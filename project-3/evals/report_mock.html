How cases are graded

  • All checks are code. REVIEW means no code rule exists yet and a person decides.
  • Planted signals compare medians of 3 runs on the changed copy against 3 runs on the unchanged copy of the same ticker.
  • "Opened" and "named" pass at 2 of 3 runs. Mentions are matched by keywords per change (for example insider, Form 4, selling).
  • NEW FAIL and fixed are measured against the run under "Compared against" above.
  • Thresholds are first guesses and will be tuned after the first real run.
